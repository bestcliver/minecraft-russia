# Россия RP / Russia RP
**Version - Minecraft Fabric 1.20.1**  
**Dependency - Fabric API**
Новые законы выдаются каждые 5 минут от введения команды начала / New laws are issued every 5 minutes from the moment the start command is given
## Команды / Сommands
/russia start singleplayer - Начать одиночную игру / Start a singleplayer game  
/russia start мultiplayer - Начать многопользовательскую игру / Start a multiplayer game  
/russia help - Получить помощь по командам / Get help with commands  
/russia restart - Перезапустить игру / Restart game  
/russia lang en - Установить Английский / Set English  
/russia lang ru - Установить Русский / Set Russian  
/russia random - Новый закон / New law
